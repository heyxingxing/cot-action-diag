1.4跨论文方法学共识：7 项实验设计底线

  1. 算力公平性必须跨过 Iso-Step 门槛：仅对齐梯度步数会掩盖 $1.5\times\text{–}3.5\times$ 的额外分支、动态采样（如 DAPO 的 $3\times$ 生成批）或裁判耗时。在线 RL 推荐采用 CRR（全计费 40.125h 等墙钟）、FACTOR（SERL-Extended 188 步等 GPU 小时）或 TRIAGE（GRPO 延至 300 步超额等壁钟）口径。
  2. 强制配备四类阴性对照与非归因强基线：凡对特定轮/token 集中赋权，必跑 Coverage, Not Targeting 式等集中度随机轮置换对照（Shuffled）；凡用分叉采样，必跑 CRR 式同分叉预算 Search-Select-GRPO 区分“信用赋值”与“筛选好分支”；并先立 ActFocus（CoT 静态降权 $\alpha\in\{0.1,0.3\}$）、FACTOR（Action-Mean 消长度偏置）与 TRCA（仅训 Action）三类零额外采样强基线。
  3. 离线估值诊断须破除“指标假象”：VinePPO 证明 Explained Variance 达 $0.7\text{–}0.9$ 的 Critic 在同状态 5 选 1 排序上仍近随机猜测（$20\%$）；ConCal 的 Gap-matched 对照证明 MSE 下降大头常来自方差收缩而非排序纠偏；C3 证明必须配独立随机种子真值 + 第二独立参考噪声上界（Noise Ceiling）。
  4. Qwen3 / Qwen3.5 专属四道工程保真门槛：① GatedDeltaNet 递归缓存 $S_t$、门控与 $A_{\log}$ 全链路锁 FP32 且权重刷新必重算缓存（Arctic-SWE）；② 严格 Token-in-Token-out 缓存原始 token ID 消除重分词漂移（AT²PO、BranPO）；③ 离线诊断开 VLLM_BATCH_INVARIANT=1 将冷重喂 $+14\text{–}28\text{ pp}$ 漂移与常规 $9\text{–}23\%$ 复现地板归零（Re-feeding）；④ 5 步 .git 清理 + 断网 + 原始 token 畸形格式严查（Arctic-SWE）。
  5. 共享随机数（CRN）须区分“优势差值”与“ANOVA 方差分解”：使用 Philox 层次键 (episode, turn, line, pos) 共享下游随机数可大幅降低成对优势差值方差，但跨分支正协方差会破坏独立样本 ANOVA 扣除公式 $\hat{B}=s^2(\bar{Q}_z)-\hat{W}/K_a$；因此全方差分解须用独立下游种子，仅在成对差值或 OPD 配对检验中用共享种子表。
  6. 训练稳定五约束：局部小状态/分支组忌除组内 std（ConCal / GiGPO / Arctic-SWE 建议去 std 或批级 RMS）；局部树优势小 $K$ 须叠加全局基线（Tree-GRPO / AT²PO）；Coding 长程 RL 忌加长度惩罚（Arctic-SWE 后期崩至 $8.4\%$）；不可丢弃失败负样本且须压制失败轨重复动作（PaTR / Self-Credit）；熵选点须加单轨上限或连续惩罚防 $93.4\%$ 预算塌缩（AEPO）。
  7. 杜绝单跑挑优，小样本评测必用同批配对 + 层次 Bootstrap：固定预设终点步数、至少 3 独立种子、附完整 Compute Ledger（FACTOR）；面对小基准（如 TB 2.1 仅 89 题），因跨批次重评漂移可达 $\pm 5\text{–}15\text{ pp}$（Coverage, Not Targeting），须在同一会话内配对评测并汇报默认/宽裕双超时预算（Benchmarks as Software）。

4.2嵌套分叉核心分解公式与无偏方差估计

在由容器快照 $\xi_t$ 与 Token-in-Token-out 精确前缀共同确定的决策点 $s_t$ 上，记 $Q(s_t, z_t, a_t)$ 为固定本轮思考 $z_t$ 与动作 $a_t$ 后由策略 $\pi$ 续跑至终局测试的期望通过率：

$$Q(s_t, z_t) = \mathbb{E}_{a \sim \pi(\cdot \mid s_t, z_t)}\big[Q(s_t, z_t, a)\big], \qquad V(s_t) = \mathbb{E}_{z \sim \pi(\cdot \mid s_t)}\big[Q(s_t, z)\big]$$ $$A(s_t, z_t, a_t) = \underbrace{Q(s_t, z_t) - V(s_t)}_{A_{\mathrm{CoT}}(s_t, z_t)} + \underbrace{Q(s_t, z_t, a_t) - Q(s_t, z_t)}_{A_{\mathrm{act}}(s_t, z_t, a_t)}$$ $$\operatorname{Var}_{z,a}\big[Q(s_t, z_t, a)\big] = \underbrace{\operatorname{Var}_z\big[Q(s_t, z)\big]}_{B\text{（想）}} + \underbrace{\mathbb{E}_z\,\operatorname{Var}_a\big[Q(s_t, z, a)\big]}_{W\text{（做）}}$$

采用 $K_z \times K_a$ 嵌套采样（默认 $K_z = K_a = 4$）时，有限样本的无偏组内/组间方差估计量为：

$$\hat{W} = \frac{1}{K_z}\sum_{k=1}^{K_z}\frac{1}{K_a - 1}\sum_{j=1}^{K_a}\big(R_{k,j} - \bar{R}_k\big)^2, \qquad \hat{B} = \frac{1}{K_z - 1}\sum_{k=1}^{K_z}\big(\bar{R}_k - \bar{R}\big)^2 - \frac{\hat{W}}{K_a}$$

注：保留原始 $\hat{B}$ 点估计（允许单决策点有限样本为负，跨决策点均值无偏），并以题目为一级聚类做 $10{,}000$ 次层次化 Bootstrap 报告 $95\%$ 置信区间；在核心 30 个决策点对每个 $(z_k, a_{k,j})$ 追加 $M_{\mathrm{roll}}=2\text{–}4$ 次独立后续续跑，以进一步把“动作之后的未来运气 $\operatorname{Var}(R\mid s,z,a)$”从组内动作方差 $W$ 中剥离。

统计学关键边界（修正《讨论稿》第五节关于共享随机数的计划）：当目标是估计两个分支的优势差值（如对比两段 CoT 或 OG-OPD 的 S vs TS 配对）时，使用 Philox 层次键 (episode, turn, line, pos) 共享下游随机性（切忌用全局单 seed）可通过正协方差显著压低差值方差；但当目标是运行上述无偏 ANOVA 全方差分解时，公式中扣除项 $\hat{W}/K_a$ 严格依赖各分支续跑残差相互独立——跨分支共享下游随机性会系统性低估组内残差、扭曲“想”与“做”的方差占比。因此，步骤 5 的 ANOVA 分解必须使用独立下游随机种子，并保留全部 $K_z \times K_a$ 分支（严禁 BranPO 式对比过滤）。

Downstream Protocol		 冻结 Qwen3.5-9B（原生 thinking 开启，$T=1.0, \text{top-}p=0.95$，全链路 FP32 GatedDeltaNet），固定剩余轮数上限与隐藏单元测试器；ANOVA 用独立种子，成对/OPD 诊断单列 Philox 共享种子结果。

6. 优化接口
Optimization Interface		 步骤 5–6 纯离线评测；步骤 7 通过保号幅值重加权或混合优势（叠加全局基线 + 批级 RMS 归一化）接入 CISPO/GRPO，配套 5 臂对照与等壁钟 / 超额等壁钟对比。
