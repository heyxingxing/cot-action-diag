$1$摘要

本页展示受控合成马尔可夫决策过程（词表大小 $V_{\mathrm{cot}}=5$，候选动作数 $V_{\mathrm{act}}=4$，回合长度 $T=4$）上的策略梯度数值实验与交互计算器，用于检验更新方程的符号性质、去混淆估计误差与数值稳定性；结论限于该合成环境，尚未在真实语言模型 RL 训练中验证。

在单轮 ReAct 自回归分解 $h_t \to c_t \to a_t \to o_{t+1}$ 下，动作 token 直接采用回合动作优势 $A_t^{\mathrm{act}}$ 更新，思维链第 $k$ 个 token 的有效策略梯度权重则写成有界因果桥梁项 $B_t^{\mathrm{cal}}$（乘以 CoT 逐 token 熵门控函数 $g_{\mathrm{ent}}$）与去历史教师非负 $k_3$ 散度项的加性组合。在 $12$ 个随机种子 $\times 120$ 轮 $\times 48$ 局/轮的合成四步 MDP 实验中：(i) 当存在无 CoT 模板格式偏移时，直接删空思考槽位的未校准桥梁（Naive-Bridge，终局回报 $1.4069 \pm 0.2789$）表现低于平权基线（GRPO-Uniform，$2.1623 \pm 0.3422$）；(ii) 经格式校准后，单独加入熵门控（Entropy-Bridge，$3.0675 \pm 0.4511$）、单独加入非负 $k_3$ 教师项（Teacher-k3-Bridge，$3.5927 \pm 0.2869$）与加性组合形式（C3A-Unified，$3.9759 \pm 0.2029$，四步全对率 $57.12\% \pm 3.75\%$）依次提升了该合成环境下的平均回报；(iii) 在扫描格式偏移强度 $\sigma_{\mathrm{OOD}} \in [0, 2]$ 的离线估计实验中，中性占位双重差分（DiD）与同组反事实交叉置换（Cross-Swap）的均方误差对 $\sigma_{\mathrm{OOD}}$ 保持不变。

$2$记号与更新方程

记第 $t$ 步完整输入历史为 $h_t$（含过往思考 $c_{<t}$、动作 $a_{<t}$ 与观察 $o_{\le t}$），去历史思考后的清洗状态为 $h_t^{\mathrm{clean}} \equiv s_t$（仅保留任务目标、历史动作与观察），本步思考序列为 $c_t = (z_{t,1}, \dots, z_{t,|c_t|})$，本步动作为 $a_t$，观察 $o_{t+1}$ 由环境返回且不计模型生成损失。引入带模板指示符的输入格式 $M_t \in \{0, 1\}$（$M_t=1$ 保留完整 Thought: … Action: 语法槽位，$M_t=0$ 直接删去 Thought: 段），未校准与校准后的长度归一化动作对数似然差分别记为：

$$\bar{\Delta}_t^{\mathrm{naive}} = \ell_\theta(a_t \mid h_t, c_t, M_t=1) - \ell_\theta(a_t \mid h_t, \varnothing, M_t=0), \qquad \bar{\Delta}_t^{\mathrm{cal}} = \frac{1}{|a_t|}\Big[\log \pi_\theta(a_t \mid h_t, c_t) - \log \pi_{\mathrm{cal}}(a_t \mid h_t)\Big]$$

其中 $\ell_\theta(a_t \mid \cdot) = \frac{1}{|a_t|}\log\pi_\theta(a_t \mid \cdot)$。在结构加性偏移假设 $\ell_\theta(a_t \mid h_t, \varnothing, M_t=0) = \mu_0(h_t, a_t) - \delta_{\mathrm{OOD}}(h_t, a_t)$ 下，有 $\bar{\Delta}_t^{\mathrm{naive}} = \bar{\Delta}_t^{\mathrm{cal}} + \delta_{\mathrm{OOD}}(h_t, a_t)$。校准基线 $\log\pi_{\mathrm{cal}}(a_t \mid h_t)$ 可由中性占位思考双重差分（DiD）或同一状态 $h_t$ 下 $G$ 条采样思考的留一交叉置换构造。

对桥梁系数施加停止梯度算子 $\operatorname{sg}(\cdot)$ 以避免对 $\log\pi_\theta(a_t \mid h_t, c_t)$ 求导时产生与 $|c_t|$ 成正比的动作梯度偏移项，定义有界因果桥梁项 $B_t^{\mathrm{cal}}$ 与 CoT 逐 token 熵门控函数 $g_{\mathrm{ent}}(\tilde{H}_{t,k}; A_t^{\mathrm{act}}, \bar{\Delta}_t^{\mathrm{cal}}) > 0$（其中 $\tilde{H}_{t,k} \in [0, 1]$ 为全词表归一化香农熵）：

$$B_t^{\mathrm{cal}} = \operatorname{sg}\!\left(A_t^{\mathrm{act}} \cdot \tanh\!\left(\frac{\bar{\Delta}_t^{\mathrm{cal}}}{\tau}\right)\right), \qquad g_{\mathrm{ent}}\!\big(\tilde{H}_{t,k}; A_t^{\mathrm{act}}, \bar{\Delta}_t^{\mathrm{cal}}\big) = \begin{cases} 1 + \alpha_+ \tilde{H}_{t,k}, & A_t^{\mathrm{act}} > 0,\; \bar{\Delta}_t^{\mathrm{cal}} > 0 \\ 1 + \alpha_-(1 - \tilde{H}_{t,k})^\gamma, & A_t^{\mathrm{act}} < 0,\; \bar{\Delta}_t^{\mathrm{cal}} > 0 \\ \rho_{\mathrm{III}}, & A_t^{\mathrm{act}} < 0,\; \bar{\Delta}_t^{\mathrm{cal}} < 0 \\ 1, & \text{其他情况} \end{cases}$$

记去历史师生对数概率差为 $D_{t,k} = \log\pi_T(z_{t,k} \mid h_t^{\mathrm{clean}}, z_{t,<k}) - \log\pi_\theta(z_{t,k} \mid h_t, z_{t,<k}) = \log r_{t,k}$。由于单点对数比 $-D_{t,k}$ 在 $D_{t,k} > 0$ 时取负值，乘非均匀权重后不再保持下界，改用逐 token 非负 $k_3$ 散度 $d_{k_3}(r_{t,k}) = r_{t,k} - 1 - \log r_{t,k} \ge 0$（在 $|D_{t,k}| < 10^{-4}$ 采用四阶泰勒展开，在 $D_{t,k} > u_{\max}$ 采用一阶切线延拓），得到单轮损失与思维链第 $k$ 个 token 的有效策略上升权重 $W_{t,k}^{\mathrm{eff}}$：

$$W_{t,k}^{\mathrm{eff}} = \underbrace{B_t^{\mathrm{cal}} \cdot g_{\mathrm{ent}}\!\big(\tilde{H}_{t,k}; A_t^{\mathrm{act}}, \bar{\Delta}_t^{\mathrm{cal}}\big)}_{\widetilde{A}_{t,k}^{\mathrm{cot}}\text{（RL 项）}} + \underbrace{\beta_T \, \omega_{t,k}\Big(\exp\!\big(\min(D_{t,k}, u_{\max})\big) - 1\Big)}_{\text{去历史教师 } k_3 \text{ 负梯度项}}, \qquad \omega_{t,k} = \mathbb{I}\!\big(B_t^{\mathrm{cal}} \cdot D_{t,k} \ge 0\big)$$

桥梁函数符号与求导边界 (i) 将带符号权重 $w_{t,k}$ 与 $D_{t,k}$ 直接相乘，在 $B_t^{\mathrm{cal}} < 0$ 且 $D_{t,k} < 0$ 时乘积变正；(ii) 对桥梁中的 $\log\pi_\theta(a_t \mid h_t, c_t)$ 直接求导会引入 $\log\pi_\theta(c_t \mid h_t) < 0$ 乘积项，改变动作头梯度符号。 采用加性分解 $W_{t,k}^{\mathrm{eff}} = \widetilde{A}_{t,k}^{\mathrm{cot}} + \beta_T \omega_{t,k}(r_{t,k}-1)$，并对 $B_t^{\mathrm{cal}}$ 施加 $\operatorname{sg}(\cdot)$。 合成实验象限 $\mathrm{IV}$ 正向误更新比例由 GRPO-Uniform 的 $91.67\%$ 降为 $0.00\%$；解析与有限差分梯度核查一致。
分 token 加权散度下界与低熵错误推理 (i) 单点对数比 $\log(\pi_\theta/\pi_T)$ 可取负值，乘非均匀正权重后连全词表期望也可为负（二元反例在 $p^* \approx 0.3651 \neq 0.8$ 处取极小值 $-2.1306$）；(ii) 低熵错误 token 处 $(1-\pi_\theta) \to 0$ 使普通策略梯度步长缩小。 教师项采用逐 token 非负 $d_{k_3}(r_{t,k}) = r_{t,k} - 1 - \log r_{t,k} \ge 0$；象限 $\mathrm{II}$ 引入 $g_{\mathrm{ent}} = 1 + \alpha_-(1-\tilde{H}_{t,k})^\gamma$。 合成实验全周期 $\min d_{k_3} = 0.0000$；工况 $2$ 低熵错误词占比由初始 $88.00\%$ 降至 $15.91\%$。
无 CoT 对比中的混杂与模板偏移 直接删去 Thought: 段（$M_t=0$）同时改变了上下文位置编码与格式分布，使 $\bar{\Delta}_t^{\mathrm{naive}}$ 混入 $\delta_{\mathrm{OOD}}(h_t, a_t)$。 保持 $M_t=1$ 模板结构，使用中性占位思考双重差分（DiD）或同状态 $G$ 条采样思考交叉置换。 合成实验 $\sigma_{\mathrm{OOD}}=1.00$ 处，$\mathrm{MSE}$ 由朴素相减的 $1.9136$ 降为 DiD 的 $0.0019$。

与 Qwen3-8B 真实模型离线诊断报告（cot_action_diag）的对照

将本页受控合成实验与工作区另一份基于 Qwen3-8B 在 ScienceWorld 和 TextWorldExpress 上采集 $3{,}299$ 步的真实离线诊断报告对照，有三个需要区分的经验事实：

  • 空 Thought 与中性 Thought 的实际偏离程度：合成实验 B 通过人为扫描 $\sigma_{\mathrm{OOD}} \in [0, 2]$ 测试不同格式偏移幅度下的估计稳健性；而在 Qwen3-8B 零样本离线诊断（E13）中，空 Thought 基线与中性 Thought 基线的 Spearman 相关为 $0.777$（SW）与 $0.849$（TWX），符号一致率为 $92.2\%$ 与 $87.1\%$。这说明在未训练基座模型上，真实格式偏移幅度接近合成实验的低偏移区间，但 RL 训练过程中策略分布变化是否会放大两类基线的差异仍需在线跟踪。
  • 去历史教师项 $D_{t,k}$ 的符号分布：在 Qwen3-8B 自教师离线诊断（E18）中，$98.4\%$（SW）与 $97.9\%$（TWX）的步满足 $\bar{D}_t^{\mathrm{self}} < 0$，同时 $C_t < 0$ 的步占 $80.1\%$ 与 $82.8\%$。这一真实分布特征直接支持表 $1$ 的加性结构：若采用乘积 $w_{t,k} D_{t,k}$ 且令 $w_{t,k}$ 继承 $C_t$ 的负号，在超过八成的步上两个负号相乘会反转更新方向。同时需注意，真实诊断中历史轮仅保留 Action: 行可能自身带有格式差异，尚待格式对照教师实验分离。
  • CoT 熵与不合法打转步的混杂：合成实验工况 $2$ 在无语法错误假设下孤立检验了低熵错误推理的梯度饱和现象；而在 Qwen3-8B 真实轨迹中，不合法步里熵最低的四分之一有 $84\%$（SW）与 $50\%$（TWX）属于失败后原样重复上一动作的“打转步”，导致步级熵分组未呈现单调差异。因此，在真实语言模型训练中启用 $g_{\mathrm{ent}}$ 时应配合打转步过滤与单因素消融。

$7$研究局限与前向计算复杂度理论估算（未实测）

  • 合成环境简化局限：本页展示的所有策略梯度训练曲线均运行在词表大小 $V_{\mathrm{cot}}=5$、动作数 $V_{\mathrm{act}}=4$、回合长度 $T=4$ 的合成马尔可夫决策过程上，尚未在真实语言模型（如 3B–8B 规模参数模型）强化学习训练中验证。

  • 前向计算复杂度理论估算（未实测）：若在 $1\text{--}2$ 张 $80\text{ GB}$ 显卡上对约 3.5B 参数模型（BF16）实施在线训练，理论上可复用 GRPO 原有的冻结参考模型（或关闭 LoRA 适配器）输入去历史状态 $h_t^{\mathrm{clean}}$ 计算 $D_{t,k}$，无需额外加载独立教师权重；在自回归采样占训练步主要耗时（约 $70\%\text{--}80\%$）且动作序列占单轮总长比例较低（约 $2.6\%\text{--}15.3\%$）的假设下，新增无梯度并行 prefill 的单步耗时增量理论估算约为 $8\%\text{--}14\%$。该数字仅为前向计算量估算，尚未在实际分布式训练框架中实测吞吐量与显存峰值。
